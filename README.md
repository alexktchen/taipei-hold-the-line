# 萬安政策島 打工・逛城市（Taipei: Hold the Line）

非官方、網友自製的 3D 政策島打工遊戲。島嶼、Q 版人物與場景的做法參考 puma.taipei 的「HEART 政策島」互動頁，全部重新實作；
玩法致敬斯普拉遁的打工模式（重新設計）：最多 4 人一隊，打倒魔王搶金蛋、搬進金蛋籃，湊滿配額撐過三波就收工。
兩個世界：**城市**（帶著自己的角色散步，在城裡花金蛋：服飾店買衣服、工地投金蛋蓋城市、找市長捐政治獻金〔遊戲裡的惡搞〕，還看得到別人正在打的班）與**打工場**（大廳＋開工，賺金蛋）。兩邊用「雲湧進來、鏡頭拉遠」的過場切換。第一次來先到打工場大廳（警語、取名字、選職業與區）；之後重新整理就直接從雲端降落到自己的區。原本的塔防在 git 歷史 `7b0db26` 以前。

## 玩法
- **12 座島 = 台北 12 個行政區**，外加獨立的**社子島**（只靠一座陸橋連到士林），依實際地理相對位置排列，每區有象徵地標。政策散落在各島，是可點的建築（大廳時點了開政策卡）。
- **打工場**：每次開工用 4～5 座相鄰的島當場地，金蛋籃放在中間那座島的廣場（島中央前方，`config.plaza`）。場地每 2 小時輪換一次（`config.rotateHours`、`config.stages`），大家同時間看到同一個場。
- **一班 3 波、每波 100 秒**（`config.shift`）：網軍從外圍島的岸邊游上岸。魔王倒下掉 3 顆金蛋，走過去就撿起來（一次一顆、搬著變慢），走進金蛋籃的黃圈算一顆；按 E／空白鍵把蛋丟出去，離籃子 2.7 格內丟會直接進籃。時間到時搬滿配額才過關，三波都過＝收工。
- **倒下與救人**：血條歸零倒下（掉出搬著的蛋），隊友走到旁邊站一下就救起來；四個人全倒這班就結束。沒被打一陣子會自己回血。
- **雜魚**（議題決定組合與頭上台詞）：鍵盤鼠、青鳥（會飛）、青蛙（打很痛）、綠鸚鵡（吐口水）、綠毛蟲（很硬）、變色龍（忽隱忽現）。
- **5 種魔王**（`config.animals` 裡 `boss: true`，大廳有魔王圖鑑）：
  - 側翼大V：頭頂舉懶人包丟人；舉著的時候猛打，包會在牠頭上爆炸。
  - 大青蛙王：瞄準一個人跳過去壓；落地後暈 2 秒、吃 1.5 倍傷害。
  - 鐵粉龍：正面有護盾（只吃 15%），衝撞後會暈，要繞到旁邊或背後打。
  - 洗版塔：上岸就不動，對人發射洗版光束（先出紅線）。
  - 飛彈鸚鵡：停在岸邊上空，對每個人發射飛彈（腳下出紅圈）。
- **特殊波**：起大霧（霧拉近、金青蛙被打會一直掉蛋）、暴走夜（晚上，暴走鼠追著被「肉搜」的人跑，打金鍵盤鼠拿金蛋）。
- **職業**（id 沿用舊的，Supabase 有檢查）：里長伯／公車司機／消防員／志工媽媽／工程師，各有自動瞄準的武器與一招特殊技（一班 2 次）：里民廣播（定身＋重傷）、公車衝鋒（往前衝撞）、水砲全開（8 秒射速 3 倍）、愛心便當（救起附近倒下的人、全員補血無敵）、台北通連鎖（打 10 隻）。
- **NPC 同事**：人不夠時補滿 4 人。會躲紅圈紅線、救人、撿蛋搬蛋、打魔王、被雜魚圍住會先拉開；適時放特殊技。名字都是虛構的。
- **操作**：電腦 WASD／方向鍵（跟著鏡頭方向）、點地面走過去（跨島自動找橋）、點敵人鎖定；Q 特殊技、E／空白鍵丟蛋、1 2 3 快速訊號、H 打工場全景、F 跟著自己、P 暫停（單人）。手機左下搖桿、右下大按鈕；單指拖曳轉鏡頭、雙指縮放。
- **打工職級**：見習生→工讀生→約聘→正職→股長→科長→局長。過關 +20 點、滿 100 升一級；失敗依波次扣點（工讀生以下不扣）。職級決定**危險度**（配額、魔王頻率與血量），一起打工時取隊員平均。記在 `heroes.grade`／`grade_pts`（沒跑 SQL 就只記在這台裝置）。
- **12 區對抗**：大廳選「替哪一區打工」，該區分數＝選那區的人搬進籃子的金蛋總數；左上面板、地圖區名掛名次。**打工榜**依金蛋排序。
- **市長 NPC**：大廳時依行政區順序巡迴政策建築宣傳；開工時站在金蛋籃旁邊當老闆廣播（開工、配額、魔王登場、催促、收工）。
- **大選前夜**（`election.date` 前一天起，台北時間）：每一波都是總攻擊議題、危險度 +15%。
- **線上人數**：Supabase Realtime presence（同一裝置多分頁算一個），名單分「打工中／在房間等／在大廳／暫離」，還在等人的公開房可以直接按「加入」。累計來過幾人＝匿名帳號數（`supabase/visitors.sql`）。

## 逛城市（買衣服、蓋城市、政治獻金都在這裡）
- 打工場大廳按「🏙 進城市逛逛」（或打完一班按「回城市花金蛋」）；城市下方工具列「🥚 去打工」回打工場。角色每次都從你選的行政區出發（衣櫃最上面可以改暱稱、職業、我的區，「🏠 回我的區」瞬間回去），穿著你用金蛋買的衣服；電腦 WASD／方向鍵、手機搖桿、或點地板走過去（跨島自動找橋，`nav.gridPath`）。
- **服飾店**（`config.explore.boutiques`，地圖上標「👕 服飾店」）：走進去才能買新衣服；買過的隨時能從「衣櫃」換。**萬聖節系列 30 套**（`config.econ.outfits.suit`，每套一句惡搞說明）：10 套免費、隨時隨地換，20 套在服飾店用金蛋買；另外帽子 8 種、背心顏色 6 種、配件 3 種。套裝會蓋過帽子、背心、配件。打工時也會穿著，其他玩家看得到。
- **打工場現況**：城市左上的小卡隨時顯示現在輪到的打工場、多久後換場（換成哪裡）、大選前夜總攻擊倒數；點小卡或工具列「🔴 打工現場」打開面板，最上面是現在的打工場（哪幾區、看一眼／走過去／去打工），下面是正在打的班與魔王圖鑑（場上有的標「🔴 場上」）。地圖上現在的打工場頭上一直掛「🥚 現在的打工場」，有人在打就變成紅色「🔴 打工中」。
- **打工現場**（工具列「🔴 打工現場」）：正在打工的房主／單人每幾秒把這一班的摘要（場、波次、剩餘時間、金蛋／配額、場上魔王、雜魚數、隊員與倒下）送到全站 `live` 頻道；城市裡列出每一班，可以「看一眼」（鏡頭飛過去）或「走過去」。有人在打工的場，頭上掛「🔴 打工中」牌子，岸外海面浮著那幾班現在的魔王（裝飾）。
- **蓋城市**（`config.econ.city`）：全站所有人投入的金蛋加總，**依序**蓋 13 項建設。正在蓋的那項是工地（名牌「🚧 名稱 進度%」），走到旁邊才能投；蓋好的建築換掉那座島上原本的一棟小房子，每個人的地圖上都看得到。其中 3 項是**填海造島**（`kind: 'island'`）：工地在連接的那座島岸邊，海上沙洲隨進度長大（浮標、起重機船），蓋好時冒出一座新島、架橋接上，可以走上去。投入的金蛋再算一次進自己行政區的 12 區對抗。
- **政治獻金**（惡搞）：走到市長旁邊才能捐，市長會回一句；全站累計到門檻解鎖**全城加成**（`config.econ.donate.tiers`）：打工受傷 −10%、配額 −1、特殊技 +1、逛城市晚上放煙火。打工的加成由房主開工時決定（開工設定的 `boost`）。大廳與逛城市時，市長巡迴每講 4 次感謝獻金榜第一名。
- 右下「衣櫃／蓋城市／獻金」按鈕打開金蛋商店面板；不在地點旁邊時按「帶我去」自動走過去。走到地點旁邊會出現「進去」按鈕（E）。
- **工具列**（下方）：時段（清晨／白天／黃昏／夜晚，時鐘從 10:00 開始一直走）、名牌開關、停住時間、鳥瞰、政策清單（搜尋、依行政區或主題分組，點一項開政策卡並走過去）、回大廳。第一次進來有三步說明。
- **多人同框**：所有正在逛城市的人都在同一張地圖上（全站 `play` 頻道，只有逛城市時才加入；訊息類型 `xp` 位置與穿著、`xe` 表情、`xb` 離開）。表情列 1～4、點別人擊掌。
- 頁面上明寫：金蛋是遊戲點數，不是錢、不能買賣；政治獻金是惡搞玩法，不是真的捐款，與任何候選人、政黨、選舉無關。
- 金蛋經濟存在 `heroes.donated`／`built`／`spent`／`outfit`／`owned`，要先跑 **`supabase/economy.sql`**（有「花的不能比賺的多」的檢查）；沒跑的話只記在這台裝置。錢包＝`eggs`−`donated`−`built`−`spent`。

## 一起打工（多人）
- **單人**：「立刻開工」＝自己＋3 位 NPC 同事，模擬全在自己的瀏覽器，不用網路。
- **房間**（`js/room.js`）：「快速配對」加入還有空位的公開房（沒有就自己開一間公開房等人）、「開房間」拿 4 碼房號＋邀請連結（`?room=房號`）、或輸入房號加入。最多 4 人，人不夠由 NPC 補；房主按「開工」，4 人到齊 3 秒後自動開工。
- **房主跑模擬**：房主的瀏覽器跑整班（敵人、金蛋、傷害、NPC），每秒 5 次把快照送給房客；房客只畫畫面、自己走路，每秒最多 6 次把位置與指令（特殊技、丟蛋、快速訊號）送給房主。特效走「事件」，只帶代碼與數字，文字由各自的 config 組出來。
- **頻道**：`shift-<房號>`（成員 presence＋房主廣播）、`shift-<房號>-u-<uid 前 8 碼>`（每位房客一條、只有房主收）。房客的訊息只送給房主，訊息量跟人數成正比。
- **斷線**：房客離開，那一格改由 NPC 代打；回來（同一個帳號）會把那一格還給他。打工中才進房的人先旁觀，下一班加入。房主離開，這班中止、房間關閉（沒有換房主）。
- **收到的都不可信**：快照、開工設定、結算一律檢查型別與範圍，暱稱只走 textContent；版本不同（`config.net.protocol`）會提示重新整理。

## 後台：新增／編輯政策與議題
靜態站的後台在 `/admin/`（Supabase 帳號登入＋`admins` 白名單）。artifact 版大廳底部「後台：政策與議題（編輯者）」只有 artifact 編輯者看得到：
- **政策**：選一筆編輯或新增；可指定行政區或「不指定（隨機落島）」；外型從既有模型挑；可填為什麼、細項（一行一條）、主責局處、相關議題。存進共享資料庫 `policies/<id>`，所有人的島上立刻多一棟。
- **議題**：選一筆編輯或新增；雜魚組合、雜魚群大小、口號、起始日。存進 `issues/<id>`。每一波從已開放的議題挑一個，決定那一波的雜魚與頭上台詞。
不走 UI 也可以直接改 `js/config.js` 的 `policies` / `issues`。同代號時資料庫的覆蓋 config 的。

## 共享後端（Supabase）
claude.ai artifact 只有登入的訪客才拿得到共享資料，無痕視窗（未登入）看不到線上人數與總戰績。公開站要用自己的後端：
1. 建一個 Supabase 專案；Authentication → Sign In / Providers → 打開 **Allow anonymous sign-ins**。
2. SQL Editor 貼上 `supabase/schema.sql` 執行（建 heroes / policies / issues 三張表與權限）。已經建好表的專案，依序跑 `supabase/districts.sql`（12 區）、`supabase/visitors.sql`（累計來過幾人）、**`supabase/shifts.sql`（打工戰績：shifts、eggs、clears、grade、grade_pts）**、**`supabase/economy.sql`（金蛋經濟：donated、built、spent、outfit、owned）**。都可以重複執行；沒跑的功能會自動退回只記本機。
3. 把 Project Settings → API 的 **Project URL** 與 **anon public key** 填進 `js/backend.js`，推上去就生效。
   - anon key 是公開金鑰，權限由 RLS 控制，可以進 repo；**service_role key 絕對不要放**。
4. 生效後：每位訪客匿名登入拿到自己的 id，戰績寫進 heroes；線上人數與打工房用 Realtime presence、一起打工用 Realtime broadcast；政策與議題從 policies / issues 讀（後台 `/admin/` 或 Table Editor 新增）。

## 部署到 Cloudflare Pages
純靜態、免 build。Cloudflare 後台 → Workers & Pages → Create → Pages → Connect to Git → 選這個 repo；Framework preset 選 None、Build command 留空、Build output directory 填 `/`。之後推 main 就自動上線。`_headers` 已設好快取。

```bash
node scripts/build-artifact.js /tmp/artifact.html
```
把輸出當 artifact 頁面，`css/`、`js/`、`vendor/` 以附檔一起發布。
