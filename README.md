# 小學闖關島 闖關・逛校園（Taipei: Hold the Line）

非官方、網友自製的 3D 小學課程闖關遊戲。題目依國小 1～6 年級常見的課程內容編寫（國語、數學、英語、自然、社會、生活），不是任何學校、出版社或教育機關的官方教材。
小鎮是動物森友會＋牧場物語的風格（`js/islands.js` 畫地面、圍欄、河、門與路網，`js/nav.js` 管可走範圍與門的開關，`js/buildings.js` 是建築與牧場小物）；人物是 Roblox 風的方塊人（`js/people.js`）；闖關玩法致敬斯普拉遁的打工模式（重新設計）。

兩個世界，用 3D 的雲海飛行切換：
- **校園（草原小鎮）**：一整片連續的草地，沒有海。13 個學期（幼兒園、一上…六下）是用木圍欄圍起來的大區塊，排在格子上、彼此緊鄰；一條小河橫過小鎮、一條支流往南，過河的地方是動森風的寬木橋。每個區塊上下左右的中間各有一道門，走過門口畫面會淡出淡入、換到隔壁的學期（牧場物語式轉場）。區塊裡有課程單元建築（點了開課程卡、按「解題任務」答題賺金蛋）、小房子、田地、乾草捲、稻草人、水井、池塘，泥土地的區塊是有牛和羊的牧場。服飾店買衣服、工地投金蛋一起蓋新校區、找校長捐書給圖書館，還看得到別人正在闖的關。
- **依學習解鎖**：一開始只開幼兒園、一年級上和自己選的學期。其他學期的門是關著的，門口的 🔒 牌子寫著要在哪個相鄰學期答對幾題（`config.unlock.need`，預設 3 題）；答對夠了門就打開。進度記在這台裝置上（`js/progress.js`）。
- **闖關場**：每個闖關場就是一個學期區塊，開始闖關時四道門關上變成競技場。最多 4 人一隊（人不夠由 NPC 同學補），一關 3 波。學習路上的小怪（粗心鼠、分心鳥、拖延蛙、複製鸚鵡、瞌睡蟲、藉口龍）從圍欄外一波波翻進來，打倒魔王（錯字大嘴鳥、大考蛙王、鐵頭龍、吵鬧塔、問號鸚鵡）會掉金蛋，搬進籃子湊滿配額才過關。闖關中隨時按 R「解題」，答對這一波金蛋 +2、血補滿。
- **人物**：Roblox 風的方塊人（方頭、黑豆眼加微笑、方身體、方手腳、方塊頭髮），走路時手腳直直擺動；帽子、套裝與手持道具照樣穿得上。

第一次來先到闖關大廳（取名字、選角色與學期）；之後重新整理就直接從雲端降落到自己的學期島。

## 解題（題庫）
- 題庫在 `js/quiz.js`：數學類（10 以內加減、20 以內加減、九九乘法、除法、看時鐘、長度、分數、大數、小數、比、圓與面積）用產生器，每次數字都不一樣；其他科目（注音、國字、造句、英語、植物、水的三態、成語、地圖、台灣地形、力、太陽系、閱讀）是手寫題庫。全部四選一，答錯會顯示正確答案與說明。
- 每個課程單元（`js/config.js` 的 `policies`）用 `quiz` 指到題庫主題、`grade` 指年級；闖關中的題目依玩家選的學期（島）年級出題。
- 獎勵（`config.quiz`）：闖關中答對這一波 +2 顆金蛋（每關最多 6 題、答錯等 12 秒）；課程卡答對每題 +2 顆記進雲端（每個單元每天 3 題有獎勵，之後只是練習；當天的次數記在裝置上）。
- 雲端要先跑 `supabase/quiz.sql`（`hero_quiz` 函式與 `solved` 欄位），沒跑的話答對會提示「金蛋沒有記錄」。

## 速算祕笈（44 招，7 章）
`js/speedmath.js` 整理了 44 招小學速算技巧，分成 7 章：加法速算（8 招）、減法速算（6）、乘以特殊數（9）、兩位數乘法妙招（9）、除法速算（6）、整除與驗算（4）、分數與百分比（2）。內容整理自國小常見的速算口訣與印度吠陀速算；網路上沒有一份公認的「44 招」清單，各家招數不同，這裡挑出常用的 44 招、統一寫法與例子。
- 每招有適合年級、口訣、經典例子，以及一個出題器：每次出不同數字，答完的說明會用那一題的數字一步步套用這招。
- 右上角「🧮 速算」或按 M 打開速算祕笈；每招按「練習」答題，答對一次得一顆星，三顆星就算學會（記在裝置上）。
- 和數學一起：課程清單多一個「#速算」科目，7 章各一棟「速算道場」放在那個年級的區塊；數學單元的課程卡有「相關速算」按鈕直接翻到那一章。
- 闖關中按 R 解題，有三成機會出自己年級可以練的速算題；跑馬燈也會輪播速算口訣。答對速算題一樣拿金蛋、也算進學期解鎖。

## 彎曲地平線（動森滾木效果）
- `js/curve.js`：用 `onBeforeCompile` 改內建材質（`MeshStandardMaterial` 等）的頂點著色器，頂點離相機越遠就往下彎：`y −= k × d²`。有兩種模式：滾木（只沿相機水平前方彎，左右不彎）和球（四面八方都彎）；腳邊一段距離保持平的。彎曲在世界座標裡做，相機俯仰角怎麼變都是往世界的下方彎；法線一起轉，遠處的光影跟著地面彎；支援 InstancedMesh；陰影用彎過的深度材質（`curveObject()` 會自動設好）。曲率和等效半徑的關係是 R = 1 / (2k)。
- 用法：`applyCurve(material)` 或 `curveObject(root)`，每幀 render 前呼叫 `updateCurve(camera)`，調 `CURVE.uCurve`、`uCurveFlat`、`uCurveMode`、`uCurveOn`。要把 DOM 名牌或點擊判定對齊彎過的畫面，用 `curvedY(x, y, z)` 算彎完的高度。
- 測試頁 `curve-test.html`：600×600 的平面草地、泥土路、行道樹與上千棵樹（InstancedMesh）、路邊房子、圍欄柱與一個方塊人，可以調曲率、平坦區、鏡頭俯角，切換滾木／球，並和「真的大圓柱／球」地面對照（半徑 R = 1/(2k)，人往前走時跟著滾）。目前只在測試頁，還沒套進遊戲本體。

## 療癒系田園小場景（`cozy-farm/`）
獨立的單一 HTML 範例（`cozy-farm/index.html`，從 CDN 載入 three@0.160），和遊戲本體無關：卡通著色（4 階 gradientMap）、反向外殼描邊、彎曲地平線、偏暖紫的柔和陰影、蜿蜒小河與木橋、會隨風擺動的草、6×4 農田（E 澆水、作物三階段）、日夜循環（晚上窗戶與路燈亮起、螢火蟲）、飄落花瓣；手機有虛擬搖桿與澆水鈕。所有模型都是程式產生的原創造型。角色是方塊積木風（`createBlockCharacter({ colors, accessories, face })`，玩家與鄰居共用）：Q 版胖嘟嘟、約 2.5 頭身：大圓角立方體頭（寬約軀幹 1.2 倍、圓角 25%）、短寬厚的軀幹加微凸肚子、短粗手臂、很短的內八小腿；臉用 CanvasTexture 畫（眼睛分開偏下、粉紅腮紅；開心／驚訝／睏）。骨架是 root → body → torso → head／arms／legs，動畫有企鵝步（左右搖、小步快頻）、每步落地 squash & stretch、待機呼吸、揮手、澆水。左上面板可以縮到最小（記在裝置上）。五位鄰居（活潑、慵懶、文青、運動、園藝）在家附近散步，靠近會揮手，按 E 聊天；F 揮手、1～3 換表情。場景物件（樹、房子、柵欄、路燈、石頭、作物）也是圓角方塊積木造型。相機：預設 45 度俯視平滑跟隨；Q／E 每次轉 45 度、右鍵拖曳自由旋轉與俯仰（30～60 度）、滾輪縮放（`CFG.cam`），手機雙指左右滑旋轉、上下滑俯仰、捏合縮放；移動方向跟著相機（W 永遠往畫面上方）；相機和角色之間的樹或房子會淡成半透明；R 或 🎥 重置鏡頭，換地圖時呼叫 `resetCamera(true)`。空白鍵澆水／收成／聊天。配色改檔案開頭的 `CFG.pal` 與 `DN`（日夜關鍵影格），地平線彎曲改 `CFG.curve`／`CFG.curveSide`。

## 怎麼玩（重點）
- 走路：WASD／方向鍵（跟著鏡頭方向）、手機左下搖桿，或直接點地板；點遠的地方會自己繞到門口。
- 闖關：武器自動打射程內的小怪，點小怪＝鎖定。Q 特殊技（一關 2 次）、E／空白鍵丟蛋、R 解題、1 2 3 快速訊號、H 全景、F 鏡頭跟著自己、P 暫停（單人）。
- 角色：班長（哨子音波、全班安靜）、體育老師（躲避球、衝刺跑）、自然老師（實驗水槍、噴水實驗）、保健老師（OK 繃飛鏢、營養午餐）、電腦老師（程式閃電、連鎖除錯）。
- 闖關等級：過關 +20 點，滿 100 升一級（新生→小學生→小組長→副班長→班長→模範生→學霸），等級越高危險度越高。
- 期末大考（`config.exam.date`）前一晚起每一波都是「期末大考」挑戰，所有小怪一起來。

## 內容都在 config
`js/config.js` 是唯一的參數檔：品牌文字、小鎮大小與河（`world`）、學期區塊與格子位置（`islands` 的 `grid`）、解鎖規則（`unlock`）、闖關場、角色、小怪與魔王、課程單元、單元挑戰（決定每一波小怪的組合與台詞）、衣服、蓋校園的建設、捐書的全校加成、跑馬燈比例。
`js/news.js`（校園快訊：小怪糗事、學習小訣竅、快問快答、校園快訊、冷知識）與 `js/hotline.js`（校園信箱：同學提問、老師解法）是跑馬燈文案。

## 共享後端（Supabase）
1. 建一個 Supabase 專案；Authentication → Sign In / Providers → 打開 **Allow anonymous sign-ins**。
2. SQL Editor 貼上 `supabase/schema.sql` 執行（建 heroes / policies / issues 三張表與權限）。已經建好表的專案，依序跑 `supabase/districts.sql`（學期）、`supabase/visitors.sql`（累計來過幾人）、`supabase/shifts.sql`（闖關戰績）、`supabase/economy.sql`（金蛋經濟）、**`supabase/quiz.sql`（解題任務）**、`supabase/admin.sql`（後台管理員）。都可以重複執行；沒跑的功能會自動退回只記本機。
3. 把 Project Settings → API 的 **Project URL** 與 **anon public key** 填進 `js/backend.js`，推上去就生效。anon key 是公開金鑰，權限由 RLS 控制，可以進 repo；**service_role key 絕對不要放**。
4. 生效後：每位訪客匿名登入拿到自己的 id，戰績與金蛋寫進 heroes；線上人數與闖關房用 Realtime presence、一起闖關用 Realtime broadcast；課程單元與挑戰從 policies / issues 讀（後台 `/admin/` 或 Table Editor 新增，格式同 `config.js`）。
5. 從舊版（政策主題）改版過來的專案：`policies`、`issues` 兩張表裡舊的資料會蓋過或加進 config 的預設，請到 Table Editor 清空這兩張表（或把舊列的 `data` 加上 `"hidden": true`）。

## 部署到 Cloudflare Pages
純靜態、免 build。Cloudflare 後台 → Workers & Pages → Create → Pages → Connect to Git → 選這個 repo；Framework preset 選 None、Build command 留空、Build output directory 填 `/`。之後推 main 就自動上線。`_headers` 已設好快取。

## 本機執行
```bash
python3 -m http.server 8080   # 在這個資料夾；然後開 http://localhost:8080
```
只有 Noto Sans TC 字型需要網路（Google Fonts）。

## 產生 artifact 版
```bash
node scripts/build-artifact.js /tmp/artifact.html
```
把輸出當 artifact 頁面，`css/`、`js/`、`vendor/` 以附檔一起發布。
